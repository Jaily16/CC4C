# CC4C 业务前端

Vue 3 + Vuex 的课程、博客与互动应用，独立于使用 Pinia 的观测端。共享组件与页面分别位于 src/components 和 src/views。

首次依赖准备、三份配置和前台启动见[项目指南](../docs/project-guide.md#配置与本机运行)。使用环境包裹辅助启动，保留 /blogImg/ 与 /avatar/ 上传映射；不要把后端秘密写入 VITE_ 变量。

目录与页面职责见[项目结构](../docs/project-guide.md#项目与目录)，项目预览资料保存在 [screenshots](screenshots)，不作为运行上传目录。
